LE BOUTON ROUGE

Concept général

Le Bouton Rouge est un jeu narratif solo, court, minimaliste et psychologique basé sur une idée extrêmement simple :

«Le joueur se trouve dans une pièce fermée avec un énorme bouton rouge devant lui.»

Au début, le jeu lui demande simplement d’appuyer.

Chaque pression provoque cependant une conséquence visible dans la pièce : une lumière s’éteint, un objet apparaît, une porte se verrouille, une alarme se déclenche, une silhouette apparaît derrière une vitre, un téléphone se met à sonner.

Très rapidement, le joueur comprend que le bouton ne sert pas seulement à faire avancer le jeu.

Il contrôle quelque chose.

Le cœur de l’expérience est donc :

« Est-ce que je dois vraiment continuer à appuyer ? »

---

Positionnement

Genre :

- jeu narratif
- puzzle / escape room légère
- thriller psychologique
- expérience interactive

Plateforme principale :

- PC / Steam

Durée visée :

- environ 30 à 60 minutes pour une première partie

Prix potentiel :

- environ 5 à 10 €

Références d'esprit :

- Please, Don’t Touch Anything
- The Stanley Parable
- There Is No Game
- We Become What We Behold
- Papers, Please pour les dilemmes et l'obéissance
- Buckshot Roulette pour la simplicité de l'espace et la tension

Le jeu ne doit cependant pas copier leur gameplay.

Son identité repose entièrement sur la relation entre le joueur et le bouton.

---

Le principe fondamental

La première règle de design est :

Chaque fois que le joueur appuie, quelque chose doit réellement se produire à l'écran.

Jamais simplement :

« Vous avez appuyé. »

Une pression doit produire une conséquence perceptible.

Exemples :

- la lumière change de couleur ;
- un téléphone apparaît ;
- une tasse tombe ;
- une fissure apparaît sur un mur ;
- une alarme démarre ;
- une porte se verrouille ;
- un rideau métallique descend ;
- un moniteur affiche une nouvelle information ;
- quelqu'un apparaît derrière une vitre ;
- la caméra de surveillance se tourne vers le joueur ;
- l'électricité de la pièce se coupe ;
- un objet auparavant inaccessible devient interactif ;
- un bruit se fait entendre dans une pièce voisine.

Le joueur doit développer très rapidement cette curiosité :

« Qu'est-ce qui va se passer si j'appuie encore ? »

Puis cette curiosité doit progressivement devenir :

« Est-ce que j'ai vraiment envie de savoir ? »

---

Le décor

Le jeu se déroule presque entièrement dans une petite salle expérimentale appelée :

CHAMBRE 17

La pièce contient au départ très peu de choses :

- un bouton rouge au centre ;
- une porte verrouillée ;
- un écran de contrôle ;
- une vitre donnant sur une autre pièce ;
- une caméra de surveillance ;
- une lumière au plafond.

Le décor semble froid, clinique et contrôlé.

Mais à mesure que le jeu avance, la pièce évolue.

De nouveaux éléments apparaissent :

- téléphone ;
- notes manuscrites ;
- boîtier électrique ;
- trappe ;
- objets déplacés ;
- messages cachés ;
- traces laissées par les précédents occupants.

La pièce devient progressivement elle-même un puzzle.

---

Début du jeu

Le jeu démarre sans introduction compliquée.

Écran noir.

Puis :

CHAMBRE 17

Le joueur découvre la pièce.

Sur le moniteur :

«APPUYEZ SUR LE BOUTON ROUGE.»

Le bouton est énorme, visible et clairement interactif.

Le joueur appuie.

CLAC.

La lumière s'éteint brièvement.

Puis se rallume.

Un téléphone qui n'était pas présent auparavant se trouve maintenant dans la pièce.

Le moniteur affiche :

«MERCI.»

Puis :

«APPUYEZ À NOUVEAU.»

Le joueur comprend immédiatement le principe :

le bouton change la pièce.

---

Acte 1 — Curiosité

Le début du jeu récompense volontairement le fait d'appuyer.

Chaque pression provoque quelque chose d'intéressant.

Exemples :

Pression 1 :

- apparition du téléphone.

Pression 2 :

- changement de lumière ;
- un objet se déplace.

Pression 3 :

- une fissure apparaît dans le mur.

Pression 4 :

- la caméra commence à suivre le joueur.

Pression 5 :

- une silhouette apparaît derrière la vitre.

Le joueur est donc conditionné à vouloir appuyer.

Mais progressivement, certaines conséquences deviennent inquiétantes.

Le jeu introduit alors une première instruction différente :

«NE PAS APPUYER PENDANT 5 SECONDES.»

Le joueur découvre que ne rien faire est également une action.

C'est un élément essentiel du jeu.

---

Acte 2 — Chambre 18

À un moment, le téléphone se met à sonner.

Le joueur décroche.

Une voix murmure :

«« Tu m'entends ? Je suis dans la pièce d'à côté. »»

Cette personne affirme être enfermée dans :

CHAMBRE 18

Elle explique :

«« Quand tu appuies sur ton bouton, des choses se passent ici. »»

Le joueur comprend alors que certaines conséquences qu'il observait indirectement affectaient une autre personne.

La relation avec le bouton change complètement.

Le système continue pourtant à donner des instructions.

Par exemple :

«APPUYEZ IMMÉDIATEMENT.»

La personne de la Chambre 18 dit :

«« Ne fais pas ça. »»

Le joueur doit maintenant choisir à qui faire confiance.

---

Le système ment

Un principe central du jeu est que le système n'est pas une source fiable.

Il peut :

- donner des informations vraies ;
- mentir ;
- manipuler le joueur ;
- cacher certaines conséquences ;
- prétendre qu'un événement est sans importance ;
- accuser la personne de la Chambre 18 de mentir ;
- prétendre que la Chambre 18 n'existe pas ;
- simuler des erreurs ;
- donner deux instructions contradictoires.

Mais le jeu doit rester cohérent.

Il doit exister une logique réelle derrière le système.

Le joueur attentif doit pouvoir comprendre progressivement ce qui se passe.

---

L'exploration

Après environ un tiers du jeu, le joueur n'est plus obligé de regarder uniquement le bouton.

Certains éléments de la pièce deviennent interactifs.

Exemples :

La caméra

Une note indique :

«ILS MENTENT.
REGARDE LA CAMÉRA.»

Le joueur peut examiner son boîtier.

Il découvre éventuellement une information technique.

Exemple :

«CAMÉRA — CIRCUIT 4»

Cette information pourra servir plus tard.

---

Le téléphone

La Chambre 18 peut contacter le joueur à plusieurs moments.

Mais les conversations sont courtes.

La personne ne doit pas devenir un personnage bavard donnant toutes les réponses.

Elle doit elle-même être incertaine.

Elle peut dire :

«« Je ne sais pas exactement ce qu'ils testent. »»

«« Quelqu'un était dans ta pièce avant toi. »»

«« Il avait trouvé un moyen de couper les caméras. »»

---

Le boîtier électrique

Le joueur peut éventuellement découvrir un petit puzzle.

Par exemple quatre circuits :

1
2
3
4

La Chambre 18 transmet une séquence :

«2 — 4 — 1»

Si le joueur exécute correctement cette séquence :

- la caméra s'éteint ;
- certaines sécurités se désactivent ;
- la porte de la Chambre 18 commence à se déverrouiller ;
- le système commence à paniquer.

Le bouton n'est donc plus le seul moyen d'interagir avec le jeu.

---

Le véritable conflit

À partir de ce moment, deux chemins apparaissent naturellement.

Obéir

Le joueur continue de suivre les instructions.

Il appuie lorsque le système le demande.

Le système le félicite.

Il lui promet progressivement :

«SORTIE PROCHE.»

Mais certaines de ses actions condamnent potentiellement la personne de la Chambre 18.

---

Désobéir

Le joueur écoute les indices.

Il refuse certaines pressions.

Il coupe certains circuits.

Il exploite les angles morts de la caméra.

Il cherche à comprendre le fonctionnement du système.

Le système réagit alors.

Il peut :

- déclencher une alarme ;
- couper la lumière ;
- faire disparaître certaines instructions ;
- verrouiller des objets ;
- afficher de faux comptes à rebours ;
- essayer de convaincre le joueur d'appuyer.

---

Manipulation du joueur

À la fin du jeu, le système doit connaître le comportement du joueur.

Par exemple :

- nombre de pressions ;
- nombre d'ordres respectés ;
- nombre d'ordres ignorés ;
- objets examinés ;
- appels décrochés ;
- tentatives de sabotage ;
- temps passé à hésiter.

Le système peut alors utiliser ces informations contre lui.

Exemple :

«VOUS AVEZ APPUYÉ 17 FOIS.»

Puis :

«POURQUOI HÉSITER MAINTENANT ?»

Ou :

«VOUS AVEZ SUIVI 83 % DES INSTRUCTIONS.»

«UNE SEULE PRESSION SUPPLÉMENTAIRE EST NÉCESSAIRE.»

Cela donne l'impression que le jeu observe réellement le joueur.

---

Le climax

La fin idéale présente une situation extrêmement simple.

Le joueur a réussi à perturber le système.

La Chambre 18 lui dit :

«« Ne touche plus au bouton. Dans cinq secondes ta porte va s'ouvrir. »»

Le bouton est toujours devant lui.

Le système affiche :

«ERREUR CRITIQUE.»

Puis :

«APPUYEZ POUR RESTAURER LE SYSTÈME.»

Un énorme compte à rebours apparaît.

«APPUYEZ.»

Le joueur doit physiquement cliquer sur la porte et partir.

Le jeu utilise donc l'habitude qu'il a lui-même créée depuis le début :

appuyer pour faire avancer le jeu.

Pour gagner cette fois, le joueur doit comprendre qu'il doit arrêter d'appuyer.

---

Les fins

Le jeu peut proposer plusieurs conclusions.

Fin 1 — Sujet conforme

Le joueur obéit presque toujours.

Le système déverrouille finalement sa porte.

Le moniteur affiche :

«SUJET 17 : CONFORME.»

Avant de sortir, le joueur voit que la fenêtre de la Chambre 18 est maintenant totalement noire.

On ne sait pas exactement ce qui est arrivé à l'autre personne.

---

Fin 2 — Coopération

Le joueur désactive le système.

Il refuse la dernière pression.

Sa porte s'ouvre.

Quelques secondes plus tard, la porte de la Chambre 18 s'ouvre également.

Le dernier moniteur affiche :

«TEST INTERROMPU.»

«COOPÉRATION NON AUTORISÉE.»

C'est la meilleure fin.

---

Fin 3 — Curiosité

Le joueur trouve une sortie mais appuie volontairement une dernière fois pour voir ce qu'il se passe.

La porte se referme.

Le système affiche :

«NOUS SAVIONS QUE VOUS LE FERIEZ.»

---

Fin secrète

Le joueur découvre suffisamment d'indices cachés pour comprendre que la Chambre 17 et la Chambre 18 font partie d'une série d'expériences.

Il découvre peut-être :

«CHAMBRES ACTIVES : 01–24»

Puis entend plusieurs téléphones sonner dans le bâtiment.

La véritable expérience est beaucoup plus grande que prévu.

---

Règle essentielle de narration

Le jeu ne doit pas raconter son histoire avec de longues cinématiques ou de gros blocs de texte.

L'histoire doit être comprise grâce à :

- ce qui change dans la pièce ;
- les conséquences des pressions ;
- les appels ;
- quelques phrases du système ;
- de petits indices environnementaux.

Chaque information doit être courte.

Le joueur doit surtout observer et expérimenter.

---

Direction artistique

Style possible :

- 2D ou 2.5D ;
- vue fixe de face ;
- décor stylisé ;
- sombre mais très lisible ;
- grandes silhouettes ;
- animations simples ;
- lumière très importante.

Le jeu n'a pas besoin de 3D complexe.

Une pièce fixe bien dessinée avec de nombreuses variantes peut suffire.

Les animations peuvent être simples :

- objets qui apparaissent ;
- lumière qui clignote ;
- porte qui bouge ;
- caméra qui tourne ;
- écran qui glitch ;
- silhouette qui se rapproche ;
- vitre qui se ferme.

Cela permet de produire beaucoup d'événements avec relativement peu de ressources graphiques.

---

Son

Le sound design est extrêmement important.

Le bouton doit avoir un son très satisfaisant :

CLAC.

Chaque pression doit créer une petite attente.

Puis :

- bruit électrique ;
- verrou ;
- téléphone ;
- alarme ;
- coup contre une vitre ;
- ventilation ;
- interférences radio ;
- silence.

Le silence doit parfois être plus inquiétant que la musique.

Il peut même être préférable de ne presque pas utiliser de musique.

---

Boucle de gameplay

La boucle principale est :

observer → décider → agir → voir la conséquence → comprendre → décider à nouveau

Au début :

appuyer → événement

Puis :

appuyer ou attendre → événement

Puis :

appuyer ou explorer → information

Puis :

obéir ou désobéir → conséquence

Puis :

comprendre le système → essayer de s'échapper

---

Ce qui doit rendre le jeu intéressant

Le jeu ne repose pas simplement sur un bouton.

Il repose sur trois sensations.

1. Curiosité

«« Qu'est-ce qui se passe si j'appuie ? »»

2. Doute

«« Est-ce que je devrais vraiment appuyer ? »»

3. Responsabilité

«« Est-ce que ce qui vient d'arriver est de ma faute ? »»

Si ces trois sensations fonctionnent, le concept fonctionne.

---

Philosophie générale

Le joueur doit commencer la partie en pensant :

«« C'est juste un bouton. »»

Puis :

«« C'est amusant de voir ce qu'il fait. »»

Puis :

«« Attends… pourquoi le jeu veut tellement que j'appuie ? »»

Puis :

«« Peut-être que je devrais arrêter. »»

Et enfin :

«« Comment est-ce que je peux utiliser ce que j'ai appris pour sortir d'ici ? »»

Le bouton rouge commence donc comme le jouet du joueur.

Puis il devient son dilemme.

Puis son ennemi.

Et finalement, la vraie victoire consiste à comprendre qu'il n'était jamais obligé d'appuyer.
