# Le Bouton Rouge

Jeu narratif court et psychologique. Une pièce fermée, un énorme bouton rouge, et une voix dans la Chambre 18.

## Jouer

Ouvre `index.html` dans un navigateur. Aucune installation n'est nécessaire.

## Documents

- `docs/CONCEPT.md` : le concept d'origine.
- `docs/ARBORESCENCE_V2.md` : la conception de la version 2 (5 fils d'actions, 20 cycles, 18 fins).
- `CLAUDE.md` : le contexte et les règles de travail pour Claude Code.
