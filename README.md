# Le Bouton Rouge

Jeu narratif court et psychologique. Une pièce fermée, un énorme bouton rouge, et une voix dans la Chambre 18.

## Jouer

Ouvre `index.html` dans un navigateur. Aucune installation n'est nécessaire.

Le prototype v1 reste jouable dans `prototype-v1.html`.

## Tester le moteur

```
node tools/test-engine.js
```

Joue 30 000 parties au hasard et vérifie que les 18 fins et les 23 situations sont atteignables.
